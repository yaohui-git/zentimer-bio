# 隐私说明

## 一句话

**所有数据只留在这台设备的浏览器里，不上传、不备份、不账号、不埋点、不订阅。**

## 具体说明

| 项 | 说明 |
|---|---|
| 采集内容 | 心率、RR 间期、呼吸率、皮肤电（S2）、体动、信号质量，以及用户主动填写的主观自评（深度 1–10、标签、备注） |
| 存储位置 | 伴侣页 `localStorage`，key `zentimer.bio.sessions.v1`；最多保留 8 场，超出自动丢弃最旧 |
| 是否上传 | **否**。仓库内没有任何网络请求、统计 SDK、崩溃上报、CDN 依赖（唯一例外：`web/flash.html` 首次烧录需从 CDN 加载烧录器，属一次性开发工具，不接触会话数据） |
| 是否账号 | 否，无登录、无用户标识 |
| 是否第三方 | 否，无广告 ID、无内购、无分享 SDK |
| 导出 | 由用户**主动点击**「导出 JSON / CSV」触发，文件保存在用户本机 |
| 删除 | 「清空本机记录」或清除浏览器数据即彻底删除；卸载/换浏览器/清缓存会丢失，请自行归档 |
| 与 zentimer 主 App | 完全独立，不读取、不写入主 App 的 SharedPreferences，不申请其任何权限 |

## 与 ESP32 热点的关系

AP 模式下手机连的是设备自己的 Wi-Fi 热点（`http://192.168.4.1`），页面由 ESP32 本地托管，数据只在手机 ↔ ESP32 的局域网内传输，**不经过互联网**。ESP32 不存储可识别个人身份的信息；S2 若做离线 Flash 缓存，只存当次会话的指标流，用户可随时清除。

## 招募志愿测试者时（若启用）

项目所有者已把「是否公开招募测试者」列为待确认事项。若启用，需额外做到：

1. 明确告知采集字段、用途、留存时长、删除方式，取得**明示同意**；
2. 主观备注里可能含个人感受，默认**不收集**自由文本，或让测试者自行决定是否填写；
3. 只收匿名化的会话 JSON（去掉 `session_id` 中的时间戳可辨识部分、去掉设备 ID）；
4. 不收集姓名、手机号、账号、位置、健康病史；
5. 提供随时撤回与删除的联系方式；
6. 涉及境内个人信息处理时遵守《个人信息保护法》，涉及境外参与者时另行评估 GDPR。
