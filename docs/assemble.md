# 组装手册（S1 指夹原型）

> 零基础版：全程不用烙铁、不用画 PCB、不用装电池、不用装 Arduino IDE。预计 30–60 分钟。

## 你会拿到

| # | 物料 | 数量 | 来源 |
|---|---|---|---|
| 1 | ESP32-C3 SuperMini 或 XIAO ESP32-C3 | 1 | `hardware/bom.csv` |
| 2 | MAX30102 模块（买「排针已焊」版本） | 1 | 同上 |
| 3 | 170 孔面包板 + 4P 母对母杜邦线 | 1 套 | 同上 |
| 4 | USB-C **数据**线 | 1 | 已有 |
| 5 | 指夹 / 魔术贴绑带 | 1 | 同上 |

工具：只要一台电脑 + Chrome/Edge。万用表可选。

## 步骤

### 1. 接线（4 根线）

照 [`hardware/wiring.md`](../hardware/wiring.md) 的表格插。要点：

- `VIN → 3V3`，**千万别接 5V**
- `SDA / SCL` 对上固件里的 `SDA_PIN / SCL_PIN`；不同批次板卡默认引脚可能不同，以丝印为准
- `INT` 不接

> 接错最多是读不到传感器，不会烧板。上电前用眼睛核对一遍 3V3 与 GND 没有短接。

### 2. 烧录（网页一键，不用装开发环境）

1. 用 USB 数据线把板子插到电脑；
2. Chrome / Edge 打开 `web/flash.html`；
3. 点 **Connect** → 选择串口（CH340 / CP2102 / 原生 USB 会自动识别）；
4. 选择 `firmware/` 里的合并镜像 `.bin`，地址 `0x0`；
5. 点 **Program**，1–3 分钟完成，自动重启。

识别不到端口？换一根数据线；或按住板子 `BOOT` 键再点 Connect。

> 烧录页首次需要从 CDN 加载烧录器，**只有这一步需要联网**；设备运行时完全离线。

### 3. 第一次点亮

1. 串口监视器 115200，看到 `I2C scan: 0x57 found` 和 `BLE advertising: zentimer-bio-XXXX`；
2. 手指轻放在 MAX30102 窗口上，**压力稳定、别捏太紧**（过紧会阻断血流，信号反而消失）；
3. 串口输出 `hr=.. rr=.. quality=..`；`quality < 0.5` 时调整手指位置、暖一下手；
4. 手机 Wi-Fi 连 `zentimer-bio-XXXX`，浏览器打开 `http://192.168.4.1`；
5. 点「开始记录」，看实时曲线；结束后填主观自评、导出 JSON。

### 4. 和 zentimer 一起用

1. 打开「静息」，选时长（15/30/45/60 分），听一声钵开始静坐；
2. 回到伴侣页点「开始记录」；
3. 结束钵响后，在伴侣页点「结束 · 写自评」；
4. 打开 `web/report.html` 看报告。

**时间靠手动对齐**，v1 不做自动同步，报告里会标注。

## 常见故障

| 现象 | 排查 |
|---|---|
| 串口无输出 | USB 线是充电线不是数据线；换线 |
| `I2C scan` 找不到 0x57 | SDA/SCL 接反或 VIN 接错；重新核对丝印 |
| `quality` 一直很低 | 手指压力、低温、指甲油、传感器窗口脏；换个手指试试 |
| 心率与手环差很多 | 先用参考心率带对照；PPG 在末梢灌注差时本来就会偏 |
| 蓝牙搜不到 | 确认固件在广播；Web Bluetooth 需 HTTPS 页面 + Chrome/Edge |
| 热点连不上 | 确认 AP 模式已开启（S1 默认），或长按按钮切换 |
