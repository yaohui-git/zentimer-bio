# 阶段 1 接线表 · ESP32-C3 + MAX30102（零焊接）

> **先读这三句**
> 1. 全部用现成模块 + 面包板 + 4 根杜邦线，**不用烙铁、不用画 PCB、不用电池**。
> 2. 阶段 1 **只用 USB 供电**（3.3V 逻辑），接错最多是传感器不亮，不会烧板。
> 3. 不同批次开发板的 I²C 默认引脚可能不同：**以板卡丝印/原理图为准**，固件里用 `Wire.begin(SDA_PIN, SCL_PIN)` 显式指定，两边对上即可。

## 最小接法（4 根线）

| MAX30102 引脚 | ESP32-C3 SuperMini | Seeed XIAO ESP32-C3 | 说明 |
|---|---|---|---|
| VIN | `3V3` | `3V3` | **不要接 5V**，MAX30102 是 3.3V 器件 |
| GND | `GND` | `GND` | 共地 |
| SDA | `GPIO8` | `GPIO4 (D4)` | 固件 `SDA_PIN` |
| SCL | `GPIO9` | `GPIO5 (D5)` | 固件 `SCL_PIN` |
| INT | 不接 | 不接 | 阶段 1 用轮询，不用中断 |

## 可选件（共用同一条 I²C 总线）

| 模块 | 接法 | 注意 |
|---|---|---|
| 0.91" OLED (SSD1306) | VCC→3V3, GND→GND, SDA/SCL→同上 | 地址通常 0x3C，与 MAX30102 (0x57) 不冲突 |
| MPU6050（阶段 2） | 同上 | 地址 0x68，若与 OLED 冲突用 AD0 改址 |
| Grove GSR（阶段 2） | AO → `GPIO2`（ADC） | **确认模块输出不超过 3.3V**，必要时加分压 |

> I²C 总线上多个设备并联即可，不需要额外的片选线。若总线不稳定，在 SDA/SCL 上各加 4.7kΩ 上拉到 3V3（多数模块已内置）。

## 上电前检查清单

- [ ] 用万用表量 `3V3` 与 `GND` 之间确实是 3.3V，没有短接
- [ ] VIN 没接到 5V
- [ ] SDA / SCL 没接反（接反只会读不到，不会损坏）
- [ ] USB 线是**数据线**（能传数据，不是只能充电）
- [ ] MAX30102 的排针已焊好（买「带排针已焊」版本可省）

## 烧录固件（不用装任何开发环境）

用 Chrome / Edge 打开仓库的 `web/flash.html`（或 ESP Web Tools 官方页面）：

1. USB 插上电脑，点 **Connect**，选择串口（CH340 / CP2102 / 原生 USB 均可自动识别）；
2. 选择固件 `firmware/.bin` 合并镜像，地址 `0x0`；
3. 点 **Program**，1–3 分钟完成，自动重启。

若识别不到端口：换一根数据线；或按住开发板 `BOOT` 键再点 Connect（部分板需要）。

## 第一次点亮

1. 打开串口监视器（115200），应看到 `I2C scan: 0x57 found` 与 `BLE advertising: zentimer-bio-XXXX`；
2. 手指轻放在 MAX30102  sensor 窗口上，**压力要稳定、不要捏太紧**（过紧会阻断血流，信号反而消失）；
3. 串口应输出 `hr=.. rr=.. quality=..`；`quality` 低于 0.5 时调整手指位置；
4. 手机连 `zentimer-bio-XXXX` 热点，浏览器打开 `http://192.168.4.1`，点「开始记录」。

## 阶段 2 加电池前的硬性要求

- [ ] 电池**带保护板**，TP4056 输出串接开关；
- [ ] 由有经验的电子工程师复核电源与人体接触部分限流；
- [ ] GSR 电极只做被动测量，**不做任何电刺激**；
- [ ] 首次上电用万用表监视电流，异常立即断电。
