网页一键烧录

zentimer-bio · 不需要装 Arduino IDE、不用装驱动、不用敲命令

步骤

  1. 用 USB 数据线把 ESP32-C3 插到电脑（不是只能充电的线）。
  2. 用 Chrome / Edge 桌面版打开本页（Web Serial 要求 HTTPS 或 localhost）。
  3. 点下面的按钮 → 选择串口（CH340 / CP2102 / 原生 USB 自动识别）。
  4. 选 firmware/ 里的合并镜像 .bin，地址 0x0。
  5. 点 Program，1–3 分钟完成，自动重启。
识别不到端口？换一根数据线；或按住板子 BOOT 键再点连接。
首次打开本页需要从 CDN 加载烧录器，只有这一步需要联网；固件运行时完全离线，不申请任何网络权限。

烧录器

S1 固件发布后，这里会换成可直接点的一键安装按钮，manifest 指向仓库 Release 里的固件镜像。当前阶段请用 ESP Web Tool 手动选择本地 .bin。

烧完之后

  1. 串口监视器 115200，确认 I2C scan: 0x57 found。
  2. 手指轻放传感器，确认 quality > 0.5。
  3. 手机连 zentimer-bio-XXXX 热点，打开 http://192.168.4.1。
  4. 回到 伴侣页 开始记录。
